# smart_tbird

Electronics for the [1968 Thunderbird restomod](https://denton.works/wrenching/thunderbird-restomod/) — sensor nodes, in-dash display, alternator delay, programming tooling, and more.

**Website:** [denton.works/microelectronics/T-bird_electronics](https://denton.works/microelectronics/T-bird_electronics/)

## Projects

| Directory | Description |
|-----------|-------------|
| [`alternator_555_timer/`](alternator_555_timer/) | Analog 555 delay for alternator field excitation — [project page](https://denton.works/projects/alternator-555-timer/) |
| [`ESP32_UDPI_Programmer/`](ESP32_UDPI_Programmer/) | ESP32 + Python CLI UPDI programmer for ATtiny3216 — [work log](https://denton.works/microelectronics/ESP32_UPDI_Programmer/) |
| [`temp_fan_node/`](temp_fan_node/) | Engine sensing node PCB (temps, voltage, fan PWM, RS-485) |
| [`display/`](display/) | In-dash display node firmware and hardware |
| [`temp_fan/`](temp_fan/) | Earlier temp/fan PCB and code |

Active development is on the `platformIO` branch.
